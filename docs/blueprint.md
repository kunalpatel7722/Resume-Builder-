# **App Name**: LinkBoost

## Core Features:

- LinkedIn Profile Score: Generates a score representing how complete a user's LinkedIn Profile is (max 100), taking into consideration aspects such as profile completeness, use of keywords, endorsements, etc. LLM may use an external tool for current profile information, or use the uploaded information to formulate its decision.
- Profile Score UI Display: A simple UI element that renders a numeric score, and displays that to the user with an encouraging message
- Profile Import: Upload your linkedIn profile from a PDF (or enter URL) in order to have the application suggest changes.
- Personalized Improvement Tips: Using Generative AI, produce at least three concrete improvement tips the user can perform, with links.
- Improvement Tips UI: Display of 3 high quality, personalized improvement tips with associated resources.

## Style Guidelines:

- Primary color: Electric Indigo (#6F00FF) to convey modernity and innovation.
- Background color: Very light gray (#F0F0F0) for a clean and professional backdrop.
- Accent color: Cyan (#00FFFF) to highlight key information and calls to action, creating contrast and guiding the user.
- Body and headline font: 'Inter', a grotesque-style sans-serif for a clean, modern and neutral look, suited to a tech-focused tool.
- Note: currently only Google Fonts are supported.
- Use minimalistic line icons for navigation and key actions to maintain a clean and modern interface.
- Emphasize a clean, modern layout with generous white space and clear visual hierarchy for a futuristic feel.
- Subtle animations and transitions to create a smooth and engaging user experience.
